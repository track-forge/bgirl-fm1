# BGIRL typography sources

ChakraPetch-Medium.ttf and Michroma-Regular.ttf, with their individual OFL notices,
retrieved unchanged from juanjiant-bit/JIANT at
`b5be0d4fa493ccf4c15e3a5255afe134b6d99107`, `assets/fonts/`.
InterTight[wght].ttf and OFL.txt were already bundled by Felucca.
All font software is SIL OFL1.1; reserved names/copyrights remain in those notices.
No JIANT renderer/generator code or other artwork is imported.

BGIRL retains S/M/L unchanged and appends scoped C/V/H roles through its existing
glyph ABI and4-bit raster pipeline: Chakra Medium12px
labels at−0.055em tracking, Inter Tight60015px values, Michroma18px sparse display
headings, and Inter Tight60028px LARGE values. Michroma is not the LARGE face.
See docs/STAGE_LAB_CUT_VERIFICATION.md at the repository root for file hashes,
coverage, table sizes, and measured verification.
